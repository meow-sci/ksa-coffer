## 2026-10-10
* **Update**: Independent review against RealAtmospheres `19dc37a`, StarMap `4dc60f8`, KittenExtensions `b524675` and decompiled build 2026.10.10.5554. The review ran `ShadowBuilder.Build` in a scratch harness against `current/Content/Core`: every anchor matched, no warning was logged and 11 shader files changed. It compiled the patched tree with `glslc`: the failures were the same 4 files that fail in the stock tree, none of them patched. It re-disassembled `CelestialSystem.GetNearbyAstronomical`, and all 50 snippets are verbatim. Changes: [Core XML entry redirect](features/core-xml-entry-redirect.md): the KittenExtensions pitfall was "unverified". It now states what the code does. The `PrepareAll` prefix keys its document by the original `mod.toml` paths, the transpiled loaders look up the swapped shadow paths, and those lookups return `null`, so Sol headers, templates and library bodies are missing (not run in game). Also added: patch order on `PrepareSystems` (before StarMap's `StarMapImmediateLoad`), that the saved last system is the template `Id`, and that `Mod.GetPath` normalizes backslashes. [Shader file redirect](features/shader-file-redirect.md): the two-mod chaining rule is corrected (the first rewrite decides, not the last). Added the main-thread `SimpleShaderStages` compiles and hot reload compiling the copy. The Linux path analysis now follows `Mod.GetPath`. [Anchor-verified text patching](features/shadow-tree-anchor-patching.md): a compile failure is caught and logged by `FileReference.Load` and surfaces later as a `NullReferenceException`. It is not thrown from loading. The face-lighting patch has four anchors, not three. [Shared shadow](features/cross-mod-shared-shadow.md): StarMap runs mods in manifest order, not name order. `_RealSharedShadow` is never listed as a mod, because `AddMods` requires a `mod.toml`. [Measured flight atmospheres](features/measured-flight-atmospheres.md): `frame:draw-ui` is replaced by `frame:viewports`, `frame:pre-render` and `frame:post-render` (audio, exhaust and plume callers). Added `ComputeDerivatives` drag, buoyancy and chutes, `UpdateRockets` via `UpdateModules`, and how the boundary moves `AtmosphereRadius` (full-physics freefall) and `PhysicsRadius`. [Reflection-only mod build](features/reflection-only-mod-build.md): a throw after the first `Patch` leaves a partly modded game, not a stock one. [ModMenu page and TOML settings](features/modmenu-page-and-toml-settings.md): StarMap's instance-path override of `DocumentsFolderPath`. [Cloud face lighting](features/cloud-face-lighting.md): four anchors. [Real Atmospheres](overview.md): hook table, shutdown note, the KittenExtensions incompatibility, the platform note and the breakage pattern. The catalog's hooks, techniques, lifecycle and game types now match the frontmatter, and it gained three how-to topics.
