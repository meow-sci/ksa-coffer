## 2026-10-10
* **Update**: Review against purrtty 71da9ef, StarMap 4dc60f8 and KSA build 2026.10.10.5554. Renamed `custom-shell-contract-via-exported-assemblies` to [custom-shell-contract-via-assembly-imports](features/custom-shell-contract-via-assembly-imports.md) and rewrote its description, hooks, steps and pitfalls: StarMap never reads `ExportedAssemblies`, so only the importer's `ImportedAssemblies` takes effect (both registration orders covered); the same correction went into the [overview](overview.md), [logging](features/brutal-logging-category.md) and [native resolver](features/per-platform-native-library-resolver.md) concepts. Lifecycle fixes: `StarMapUnload` runs after StarMap's `UnpatchAll()` has removed every patch and StarMap has no in-process reload, so purrTTY's unpatch and static resets are defensive ([overview](overview.md), [failure-isolated patching](features/failure-isolated-harmony-patching.md), which also no longer claims every patched method is first called after `StarMapAllModsLoaded`); the stock console executes commands in `frame:input`, not `OnDrawUiConsole`, so the [Game Console shell](features/game-console-shell.md) runs them after physics dispatch; the [translucency postfix](features/draw-after-translucency-pass-postfix.md) fires per call site (secondary viewports, main view, editor) with corrected call-site anchors; the [menu fallback](features/game-menu-with-modmenu-fallback.md) also runs from secondary viewports' menu bars inside `OnDrawUiViewports`; `StarMapAfterGui` work (input-gate flag, off-screen renders) only happens in HUD-visible frames ([input gate](features/gate-game-input-while-terminal-focused.md), [render-to-texture](features/offscreen-imgui-context-render-to-texture.md), [quad pipeline](features/world-space-quad-pipeline-custom-shader.md)); the renderer exists before mod hooks while `Program.OffscreenTarget` appears only after `ModLibrary.LoadAll` ([upgrade skill](features/ksa-upgrade-coupling-review-skill.md)). Also fixed the hot-zone z-order claim ([lock mode](features/click-through-lock-mode-hot-zone.md)), the logging first-use hook, a loose snippet range, added a stale-MSAA pipeline pitfall, synced the overview feature table with frontmatter, made a mod-specific how-to slug generic in `ai/catalog/purrtty.yml`, and regenerated indexes.
