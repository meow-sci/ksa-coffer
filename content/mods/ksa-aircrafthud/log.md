## 2026-10-11

## 2026-10-10
* **Update**: Independent review against KSA_AircraftHUD `4e4c717`, ShaderExtensions `6a2eb66` (and its `v0.4.0` tag for the version notes), StarMap `4dc60f8` and decompiled build 2026.10.10.5554. Added [Always-on ImGui hook from a Program.OnFrameEditor postfix](features/always-on-onframeeditor-hook.md) (category patching): frame position of the postfix, what is safe there, skipped `Exit` frames, one-frame camera lag, and a comparison with the other hidden-UI hooks. [Surface attitude and air data from the controlled vehicle](features/flight-data-from-vehicle.md): new pitfalls for the g-load, which subtracts gravity from `AccelerationBody` although that value already excludes it (`PhysicsStates`, `ConstraintSim`, the game's own `G-FORCE` readout); for the `(Celestial)` parent cast, which throws on every frame for a vehicle orbiting a star (`StellarBody` is not a `Celestial`) and is not caught anywhere up to `App.Run`; for per-frame console output on airless bodies; and for imperial altitude hiding the attitude block. Also documented the 90-degree shift on alpha/beta, corrected the Mach visibility condition, and reworded the lifecycle note (the next step is already in flight; reads are consistent, writes would race). [Fullscreen draw-list HUD](features/fullscreen-drawlist-hud.md): lifecycle bullets now state the in-flight physics step, the skipped `Exit` frames and that the back-of-z-order placement is Dear ImGui behaviour; added why the startup viewport size is valid (`Loading.OnFrame`) and the imperial altitude cut-off. [Custom TTF font in the ImGui atlas](features/custom-hud-font.md): the font-rebuild pitfall now says the rebuild frame skips the HUD and the next `PushFont` gets a dangling pointer. [Curved, chromatic HUD window via an ImGuiShader](features/imgui-window-hud-shader.md): replaced the claim that off-screen elements extend the shader quad (vertices are clip-clamped) and dropped the unverified visibility claim for the 1/255-alpha rectangle; added that only `RenderGame` is patched and that the shader keeps applying with the UI hidden. [Canopy-glass post-process chain](features/glass-post-process-chain.md): added that the chain runs on the HDR `R16G16B16A16SFloat` image, that its output is not shown with CMAA2 anti-aliasing, and that `CurvedUV` ignores its arguments. [Spatiotemporal blue-noise dithering](features/blue-noise-dithering.md): corrected the 8-bit banding rationale (the pass runs before tonemapping) and the time base (player time). [ShaderExtensions push constants and uniform buffers from C#](features/sx-push-constants-and-buffers.md): a pass skipped by ShaderExtensions does not cause a `NullReferenceException` (its push constant is registered at load); added that the `Size` attribute on push constants is ignored. [INI settings file and settings window](features/ini-settings-and-settings-window.md): eleven keys, not ten; the `MenuBar` flag only adds an empty strip and nothing goes into the game's separate `Menu Bar` window; a parse exception stops the game at mod loading. [ModMenu entry with a vendored attributes DLL](features/modmenu-entry-vendored-attributes.md): timing note tied to `Program.DrawMenuBar` and marked conditional on ModMenu's unverified hook. [KSA_AircraftHUD](overview.md): loader table and data flow state the in-flight physics step and the `Exit` frames, compatibility now separates the rejected post-process passes from the unaffected `ImGuiShader`, names the KittenExtensions Continued requirement and the CMAA2 limitation, and lists the data bugs; feature table gained the new concept and the missing `frame:viewports` lifecycle of the glass chain. Catalog synced (hooks and game types of the font and flight-data features, new feature, new how-to topics). The game-loop reference was updated in the same review; see its log.
