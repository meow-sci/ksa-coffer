* **Update**: How-to review. [A ballistic computer that flies any player-built rocket to a latitude and longitude](features/icbm-ballistic-computer.md) repeated the mod's claim that the ecliptic carries about 54 million km of planet travel in a half-hour flight; 29.8 km/s over 1,800 s is about 54,000 km, so the page now gives that figure and notes the slip in the mod source.
* **Update**: Game-loop reference consistency review (build 2026.10.10.5554 `Program.cs` L2443-L2481, L4308-L4436; `PhysicsBubble.cs` L793-L796; `GaugeCanvas.cs` L143). [Round bodies drawn past the engine's pixel cull](features/round-body-draw-hooks.md) labelled its `Vehicle.UpdateRenderData` postfix and `PartModelRenderer.UpdateRenderData` prefix `frame:pre-render` and said the conventions file `UpdateRenderingResources` there; both run inside `Program.Render` after `OnPreRender` returned, which the game-loop reference (per-frame row 22) and the conventions label `frame:render`. The `lifecycle` value, the timing paragraph, the overview's feature table and `ai/catalog/ksarmory.yml` now say `frame:render`. [PrepareWorker prefix command window](features/prepareworker-prefix-command-window.md) said the stock staging recompute runs while "the staging canvas or the engine-control gauge is open"; it now names the `Sequence` and `EngineControl` gauge canvases, says the recompute runs on the vehicle-solver worker, and states that both canvases start enabled, so with the default UI it runs every step.
