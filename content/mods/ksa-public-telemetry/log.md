## 2026-10-11

## 2026-10-10
* **Update**: Independent review against KSA-Public-Telemetry `90608fb`, StarMap `4dc60f8` and decompiled build 2026.10.10.5554. Added [Allocation-free formatted readout text](features/allocation-free-readout-text.md) (span formatting into Brutal's per-frame `ImString` arena). [Keep drawing while the game UI is hidden](features/draw-while-ui-hidden-drawfps-postfix.md): `DrawFps` is not the only UI-phase call outside the `DrawUI` guard (`OnDrawUiConsole` follows it), the postfix skips `PrepareFrame` `Exit` frames, and hi-res screenshot capture also forces `DrawUI` false. [Broadcast overlay](features/foreground-drawlist-broadcast-overlay.md): the game's FPS counter uses the background, not foreground, draw list; the menu-bar inset reads last frame's bar window because `StarMapAfterGui` runs before `OnDrawUiThreadSafe`. [Freeze on signal loss](features/freeze-on-signal-loss.md): a fraction of 1.0 destroys the whole vehicle in the same `ApplyVehicleSolvers` call (not part breakage), g limit from `VehicleStructuralLimits`, peaks are per step, EVA never freezes (`KittenEva.IsControllable` is always true). [JSON config](features/json-config-in-documents.md): the final `StarMapUnload` save ignores StarMap's instance path because `UnpatchAll()` has removed the documents-path prefix, and the file is always written at unload. [Every element as its own ImGui window](features/panels-as-static-imgui-windows.md): windows share the sampler's snapshot object, so they are not a frame behind the bar. [Montserrat fonts](features/montserrat-fonts-in-imgui-atlas.md): `RegenerateFonts` hazard made concrete and the manifest `fonts` key explained. [Live flight telemetry sampling](features/live-flight-telemetry-sampling.md): `AccelerationBody` is the felt acceleration (resolved from the decomp) and `StarMapAfterOnFrame` also fires on `Exit` frames. [Mission timeline](features/mission-timeline-with-planned-burns.md): `Burn.Time` is the impulsive instant, ignition is half a burn earlier. [Engine diagram](features/engine-diagram-from-nozzle-positions.md): stock engines exhaust along -X, gimbal deflection is ignored. [Hide and restore the stock flight HUD](features/hide-and-restore-stock-flight-hud.md): only the `Burn` canvas is `AlwaysEnabled`, canvases are also skipped by `CanvasesRender`, and suppressed flags are never persisted outside layout saves. Also tightened timing wording (state applied this frame with the next step in flight) across the clock, events, hotkeys, intro and error-budget concepts, added the `DrawFps` postfix to the hooks of every concept drawn through the overlay, and updated the overview and `ai/catalog/ksa-public-telemetry.yml`.
