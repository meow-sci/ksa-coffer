## 2026-10-10
* **Update**: Game-loop reference consistency review. The description of [Per-frame effect parameter upload](features/per-frame-parameter-upload.md) said MPFX writes the film grain push constants "every frame" from `StarMapAfterGui`; that hook is skipped while the HUD is hidden (`DrawUI` false), as the page body already states, so the description (and the summary in `ai/catalog/mpfx.yml`) now says "every frame the HUD is shown". Indexes regenerated.
* **Update**: Independent review against MPFX `fbdeeeb`, ShaderExtensions `6a2eb66`, StarMap `4dc60f8` and decompiled build 2026.10.10.5554 (including the IL of `Program.RenderGame`). Asset declarations, the RenderPassId order, the Id-based buffer sharing, the `SubpassId`/`RequiresUniqueRenderpass` rejection, the attribute-name coupling, the std140 layouts and the set 1 binding contract were confirmed. Fixes: [Effect chain declared as RenderPassId-ordered post-process assets](features/effect-chain-assets.md) now states that with CMAA2 anti-aliasing the pre-ImGui chain runs but is not displayed (`RenderAaPreparePasses` tonemaps the offscreen image before the hook and the final blit reads CMAA2's own target), qualifies the film-grain HDR clamp accordingly, names the `RebuildRenderer` postfix hook, notes that equal `RenderPassId`s run in load order (stable `OrderBy`) and when `SubpassId` rejection happens. [Shader contract for chain passes](features/effect-shader-contract.md) no longer claims set 0 is bound with the current frame's dynamic offset (the reflected `currentFrame` field is `_currentFrame` in this build, so the offset is always 0, and set 0 has no dynamic bindings), says the parameter block is a `UniformBufferDynamic` descriptor at offset 0 and that binding numbers skip push-constant children, and limits the "first member pre, second member post" rule to the shared-buffer effects. [Per-frame effect parameter upload](features/per-frame-parameter-upload.md) now explains that `StarMapAfterGui` runs after the next physics step is dispatched and before the frame-slot fence wait in `OnPreRender`, so a dirty-flag write can reach the previous frame still on the GPU, and when `RenderGame` is not recorded. [Uniform buffer and push constant structs bound by attribute name](features/duck-typed-buffer-structs.md) names `ModLibrary.Bind` as the point where buffers are created. [Separable Gaussian blur with CPU-computed weights](features/separable-gaussian-blur.md) no longer says weights are recomputed only on radius changes. Smaller fixes in [MPFX](overview.md) (README effect list, `ImportedAssemblies` on the ShaderExtensions dependency, CMAA2 and hard-coded-local compatibility notes, `Serializer.cs` source), [Color grading shader math](features/color-grading-math.md), [Film grain and experimental effects](features/film-grain-and-experimental-effects.md), [Effect profiles as XML assets with clipboard export](features/xml-effect-profiles.md) and [Effect settings window and ModMenu entry](features/effect-settings-window.md) (`// ...` on truncated snippets, line anchors). Catalog updated with the new hook and two how-to topics.
